HumanFrame technology

Engineering the whole experience.

Physical design, interactive software and application workflows need to work together. HumanFrame develops them as one research platform.

Interaction is a system.

Speech, expressive feedback, touchscreen content and camera inputs become useful when an application can coordinate them. We’re developing that connection alongside the physical robot.

Early software integrations provide a working foundation. Bringing them into a complete, consistent research unit is ongoing engineering work.

One software foundation.

The runtime coordinates supported robot services and application execution. The SDK is being developed to give applications consistent access to those services. The Platform supports packaging, deployment and execution information.

For application developers

Bring your ideas into the physical world.

HumanFrame is developing a software environment for building interactive applications on its own research robot.

A consistent way to build.

The SDK is intended to connect application behavior to supported speech, audio, camera, display and expression capabilities through reusable interfaces. The runtime coordinates application execution and robot services.

A Python-first prototype is part of the current development foundation. Broader interfaces and complete robot integration are still in development; there is no public SDK release or download available here.

An evolving developer workflow

Build, package, run, refine.

Existing prototype work supports application validation, installation and execution. The application Platform adds upload, robot selection, deployment information and logs to the development workflow.

These foundations are being connected into the complete research platform. Standardized interaction services and research-specific tools remain under development.

Application contract

Small by design.

The current runtime supports trusted Python web applications. A manifest names the entrypoint, declared port, version and optional capability requirements.

{
  "name": "Hello World",
  "version": "0.1.0",
  "type": "web",
  "entrypoint": "app.py",
  "port": 5000,
  "required_capabilities": []
}
01

Validate

Package admission checks the manifest, paths, archive limits and declared entrypoint before storage.

02

Run

Each deployment receives an isolated runtime, assigned port, process tracking and a required HTTP health check.

03

Observe

Status, application output, logs and previews stay attached to the deployment record.

Developer access is private

This static website contains no account creation, upload or deployment interface. The operational HumanFrame Platform is intentionally not part of this deployment.

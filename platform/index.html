The current Platform turns a compatible Python web application into a validated artifact that can run locally or on a registered SSH-accessible Linux robot.

Current workflow

A direct path to a running application.

  1. 01
    Create

    Build a compatible Python web application.

  2. 02
    Package

    Add the manifest, entrypoint and requirements.

  3. 03
    Upload

    Validate and store the artifact.

  4. 04
    Select

    Choose the development machine or registered robot.

  5. 05
    Deploy

    Prepare the runtime, start and health check.

  6. 06
    Monitor

    Inspect status, logs and preview.

Private Platform access

This public website describes the current Platform, but it does not expose login, registration, application uploads, robot controls or any Platform endpoint. Platform deployment remains separate.

Current scope

Trusted Python web applications, local development targets and SSH-accessible Linux robots. Broader runtime and agent capabilities remain future work.
